pitch prediction game. Code and teaching materials were prepared with Codex
assistance. Reviewing generated code and independently extending it are separate
learning steps.

## Source and verification receipts

The [October 16 local audit](../../reports/dataset-audit-2026-10-16.json)
processed 1,485 records and 53 columns across seasons 1-17. Season 17 contains
44 records and is a partial snapshot. Validation accepted 1,481 rows; four rows
lack outcomes, original asks and offered equity and were quarantined.
Accepted rows contain 914 recorded deals and 567 recorded no-deals.

The [manifest](../../data/manifest.json) records Kaggle's CC0/Public Domain label
and both checksums. That label does not establish video/logo rights or independently
verify historical facts. Recorded deals do not prove funding closed after filming.

passed 14 tests plus compilation on each of Python 3.11 and 3.12 at the code commit
above. These are the same 14 tests on two runtimes, not 28 unique tests. The receipts
were rechecked on October 18; tests were not rerun locally for this documentation
update. CI uses synthetic fixtures and does not download the real archive.
The real-data audit was a separate local run.

## Next learning step

Allow 15-20 minutes to explain probability versus outcome and follow one row into
the pre-reveal representation. For guided practice, calculate `(p - y) ** 2`
for a 60% deal prediction when no deal occurs; then write a small test yourself.

Explain why final deal equity must not become a prediction input. A future model
also needs a separate feature policy, a season-aware held-out split, train-only
preprocessing and a constant-probability baseline. Startup names and repeated
companies require special care even when the name is visible before a reveal.

Review the current slice and attempt the exercise before implementing a new
subsystem. This checkpoint does not establish independent mastery.
